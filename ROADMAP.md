# Что дальше

Идеи, которые мы обсудили и отложили на потом. Порядок примерный — что-то может переехать раньше.

## Скоро

- **CurseForge** — поиск и установка, как с Modrinth. Ждём ключ API (импорт .zip уже умеет работать с ключом).

## Сборки и моды

- **Профили модов** — несколько наборов модов в одной сборке («для выживания», «для съёмок»).
- **Сравнение сборок** — какие моды есть в одной и нет в другой.
- **Откат по истории** — история изменений уже есть, следующий шаг — вернуть мод одной кнопкой.
- **Машина времени** — снимок всей сборки целиком перед большими изменениями.
- **Spectia Doctor 2** — больше «примет» ошибок и советы ещё до запуска игры.

## Удобство

- **Ctrl + K** — быстрый поиск по всему лаунчеру: сборки, моды, настройки.
- **Мини-режим** — маленькое окошко «Играть» без всего остального.

## Красота

- **Галерея тем** — делиться своими темами с другими (для этого нужен сервер).
- **Свой CSS** — для тех, кто хочет поменять вообще всё.
- **Живые обои** — видео на фоне. Не срочно.

## Статистика

Spectia уже тихо записывает игровые сессии у вас на компьютере (никуда не отправляет), чтобы потом из этого получились:

- **Подробные графики** — по месяцам и по сборкам (недельный график уже на главной).
- **Spectia Wrapped** — красивые итоги года.
- **Достижения** — маленькие награды за игру и за порядок в сборках.

## Расширения

- Возможность добавлять в Spectia свои функции, не меняя сам лаунчер.
